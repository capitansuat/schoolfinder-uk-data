# SchoolFinder UK – Data

Public release-asset host for the bundled SQLite database the SchoolFinder UK
app downloads via its in-app "Update data" button.

Each release contains:

- `schools.sqlite` — full database
- `version.json` — `{ "version": "<tag>", "publishedAt": "<iso>", "sha256": "<hex>" }`

Source data is sourced from public DfE / Ofsted / data.police.uk datasets.
